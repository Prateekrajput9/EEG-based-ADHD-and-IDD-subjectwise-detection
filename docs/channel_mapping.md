## Harmonisation for cross-dataset runs

- DS-2 is additionally band-pass filtered to 1–30 Hz (4th-order Butterworth), so that the
  two datasets are compared over a common band.
- Features are scale-free, 10 per channel, so amplifier gain and reference differences
  matter less: relative delta/theta/alpha/beta power, log theta/beta ratio, spectral
  entropy, Hjorth mobility and complexity, sample entropy and permutation entropy.
- `train_stats` mode standardises with the training dataset's statistics. `own_stats`
  mode (†) standardises each dataset with its own statistics, which uses unlabelled
  test-dataset data.
- The dataset-ID control trains a classifier to tell DS-1 windows from DS-2 windows. High
  accuracy there means the datasets are separable before any disorder signal is
  considered.

Cross-dataset training and testing pairs different disorders (IDD vs. ADHD), headsets and
tasks. It is a **domain-shift test**, not evidence that one disorder model transfers to
another.
